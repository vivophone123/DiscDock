# DiscDock – Problem Statement

**รายวิชา:** Advanced Computer Programming
**โปรเจ็กต์:** Mobile App Mini Project (Micro-commerce)
**ผู้จัดทำ:** นาย ธนายุต เพ็งกุล (<116710906038-0>)
**GitHub:** https://github.com/vivophone123/DiscDock

---

## 1. ภาพรวมแอป

**DiscDock** คือแอปร้านขายแผ่นเกมขนาดเล็ก (PS5, PS4, Nintendo Switch) ทั้งมือหนึ่งและมือสอง
ลูกค้าเลือกเกม ใส่ตะกร้า และชำระเงินได้ในแอป ส่วนเจ้าของร้านจัดการสินค้า ออเดอร์ และดูยอดขายได้จากหน้า Dashboard

## 2. ผู้ใช้เป้าหมาย

| ผู้ใช้ | รายละเอียด |
|---|---|
| เจ้าของร้าน | คนขายแผ่นเกมรายย่อย ปัจจุบันรับออเดอร์ผ่านเพจเฟซบุ๊ก ไลน์ หรือกลุ่มซื้อขาย |
| ลูกค้า | เกมเมอร์ที่ต้องการแผ่นเกมแท้ ราคาเป็นธรรม และเชื่อถือร้านได้ |

## 3. ปัญหาที่พบ (Pain Points)

1. **ถามซ้ำๆ ในแชท** ลูกค้าต้องทักถามว่ามีเกมนี้ไหม เป็นแผ่นเครื่องอะไร มือหนึ่งหรือมือสอง โซนไหน (Region 1/2/3, Asia)
2. **สต๊อกไม่ตรง / ขายซ้ำ** แผ่นมือสองมักมีชิ้นเดียว ถ้าขายให้สองคนต้องขอโทษลูกค้า
3. **ชำระเงินยุ่งยาก** ลูกค้าโอนเงินแล้วต้องส่งสลิป รอเจ้าของร้านมายืนยันเอง
4. **ไม่แน่ใจสภาพแผ่นมือสอง** เช่น รอยขีดข่วน มีกล่องหรือไม่มีกล่อง
5. **เจ้าของร้านไม่เห็นภาพรวม** ไม่รู้ว่าเกมไหนขายดี หรือควรสั่งของเข้าเพิ่มอะไร

## 4. ฟีเจอร์ที่แก้ปัญหา

| Pain point | ฟีเจอร์ที่แก้ |
|---|---|
| 1 | ค้นหา/กรองตามแพลตฟอร์ม แนวเกม สภาพ ช่วงราคา และปุ่มแชทถามร้านจากหน้าสินค้า |
| 2 | ตัดสต๊อกอัตโนมัติเมื่อสั่งซื้อ แสดงป้าย "เหลือ 1 ชิ้น" และไม่ให้สั่งเกินสต๊อก |
| 3 | ชำระเงินและยืนยันการชำระในแอป ไม่ต้องส่งสลิป |
| 4 | อัปโหลดรูปแผ่นจริงได้หลายรูป และมีตัวเลือกสภาพ/กล่อง |
| 5 | Dashboard แสดงยอดขาย เกมขายดี แผ่นใกล้หมด |

**ฟีเจอร์ตามโจทย์:** ระบบสมาชิก, เลือกสินค้า + ตะกร้า + ชำระเงิน, เพิ่ม/ลบ/แก้ไขสินค้าพร้อมตัวเลือกย่อย, Dashboard เจ้าของร้าน, ค้นหา/หมวด/ตัวกรอง, แชทลูกค้า-ร้าน (ข้อความ/รูป), คูปองส่วนลด, ประวัติคำสั่งซื้อ, สต๊อก, อัปโหลดรูปหลายรูป

## 5. โฟลว์หลัก

**ลูกค้า**

สมัคร/ล็อกอิน → หน้ารายการเกม (ค้นหา/กรอง) → รายละเอียดเกม (เลือกแพลตฟอร์ม/สภาพ ดูรูปแผ่นจริง) → ตะกร้า (ใส่คูปอง) → ชำระเงิน → ยืนยันคำสั่งซื้อ → ประวัติคำสั่งซื้อ / แชทกับร้าน

**เจ้าของร้าน**

ล็อกอิน → Dashboard → จัดการสินค้า (เพิ่ม/ลบ/แก้ไข อัปโหลดรูป ตั้งสต๊อก) → รับออเดอร์ (รอชำระ → เตรียมส่ง → ส่งแล้ว) → ตอบแชท

## 7. ธีม/รูปลักษณ์

- **โทน:** Dark mode เหมาะกับสไตล์เกม
- **สีหลัก:** ม่วงนีออน `#6C5CE7`
- **ดีไซน์:** Material 3 (`ColorScheme.fromSeed`)
- **ฟอนต์:** Prompt 
- **ไฟล์ธีม:** `discdock/lib/app/theme.dart`

## 8. เทคโนโลยีที่ใช้

- **Frontend:** Flutter (Dart)
- **Backend/Cloud:** Firebase (Authentication, Cloud Firestore, Storage, Cloud Messaging)
- **ชำระเงิน:** Payment gateway แบบ test mode (เช่น Stripe หรือ Omise/PromptPay)
- **ทดสอบบน:** อุปกรณ์จริง (Android)
